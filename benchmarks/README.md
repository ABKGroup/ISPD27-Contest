# ISPD 2027 Contest Benchmarks

This directory contains the public benchmarks for the ISPD 2027 Contest on **MCMM Post-CTS Buffering and Sizing**.

As of **October 5, 2026**, two public benchmarks have been released:

- `aes`
- `jpeg`

Additional public benchmarks will be added gradually.

We will release **six public benchmarks** in total. The public benchmarks are used only for tool development, debugging, and testing. **Final contest scores and rankings will be determined solely by performance on the hidden benchmarks.**
